# PlaywrightDemoProject

A demo automation project built using **Playwright** with **JavaScript**, showcasing end-to-end testing capabilities for modern web applications.

---

## 📌 Features
- End-to-end UI automation using Playwright
- Page Object Model (POM) structure
- Data-driven test examples
- Cross-browser testing (Chromium, Firefox, WebKit)
- Easy integration with CI/CD pipelines
- HTML test reports

---

## 🛠️ Tech Stack
- **Language:** JavaScript (Node.js)
- **Framework:** Playwright Test Runner
- **Reporting:** Playwright HTML Reporter / Allure (optional)
- **Version Control:** Git & GitHub
